# SPEC-001：App 切换器行为契约

上游：[PRD-001](prd.md)；设计：[DESIGN-001](design.md)；验证：[QA-001](test-plan.md)、[TRACE-001](traceability.md)。本文定义 V1 的对外可观察行为，为 accepted 基线后即作为实现与验收的权威依据。

## 目标与适用范围

- 用户任务：唤出覆盖层 → 识别键位 → 按键切换 / 取消。
- 角色与前置：本地单机用户；应用已授予「辅助功能」权限。
- 非目标：窗口级切换、窗口预览、手动固定键位、Hold 快速路径、切 Space、未运行 app 启动、模糊搜索（见 [PRD-001 非目标](prd.md)）。
- 领域术语：候选 app = 正在运行且 `activationPolicy == .regular`、且非本应用自身的 app；rank = 由使用统计（激活次数降序、最近激活降序、名称升序兜底）得到的排序。

## 行为与状态

| 起始状态/触发 | 条件与权限 | 预期结果/副作用 | 失败、取消或恢复 |
| --- | --- | --- | --- |
| 按下全局热键（默认 `⌥+Space`） | 已授权辅助功能 | 覆盖层在当前活动显示器出现，列出候选 app 映射到键位 | 未授权时切换类操作给出明确反馈，不静默失败 |
| 覆盖层打开中，按下某映射键 | 该键有 app | 立即收起覆盖层并激活该 app 置前；跨桌面则跟随系统切换 | 无映射键的按键忽略（或作为无操作），不收起 |
| 覆盖层打开中，按 Esc / 点覆盖层外 / 再按热键 | 任一 | 收起覆盖层，无任何切换副作用 | 无 |
| app 集合或使用统计变化后唤出 | 已授权 | 键位重新计算，仍保持确定性；存活 app 尽量保持原键位 | 无 |

覆盖层仅展示，不改变 app 运行状态；激活失败（如目标 app 已退出竞态）不伪造成功，收起后状态以系统为准。

## 键位分配规则（行为级定义）

- 键位集合（38）：字母 `A–Z`（26）+ 数字行 `1 2 3 4 5 6 7 8 9 0 - +`（12）。
- 候选按 rank 从高到低依次分配：
  1. 若显示名首字符是小写/大写字母 a–z，理想键 = 该字母。
  2. 理想键空闲 → 分配；否则就近让位到**最近的空闲字母键**（QWERTY 距离；距离相同优先 home row，再优先更靠左的键）。
  3. 若显示名首字符不是 a–z，或 26 个字母键全部占满 → 依次落入数字行 `1…0 - +`。
- 候选超过 38 个时，按 rank 截断为 Top 38，其余不显示。
- 确定性：给定相同候选集合与相同使用统计，映射完全一致。

## 可验收条件

| AC | 给定/当 | 必须观察到的结果 | 验证方式 |
| --- | --- | --- | --- |
| AC-01 | 已授权，按下配置的全局热键 | 覆盖层在当前活动显示器出现，呈键盘形状，列出候选 app（图标+名称）并映射到键位 | TEST-001 |
| AC-02 | 运行多个 app（含本应用自身、菜单栏/后台 app） | 覆盖层只包含 `activationPolicy == .regular` 且非本应用自身的 app；>38 个时截断 Top 38 | TEST-002 |
| AC-03 | 同一候选集合+同一使用统计，连续两次唤出 | 两次键位映射完全一致；首字母唯一者落在其首字母键位 | TEST-003 |
| AC-04 | 多个 app 首字母相同（如 Safari/Slack/Spotify） | rank 高者占首字母，其余就近让位（距离相同 home row 优先、再靠左）；字母区满后落入数字行 | TEST-004 |
| AC-05 | 覆盖层打开，按下某有映射的键 | 覆盖层立即收起，目标 app 被激活置前；跨桌面跟随系统切换（接受系统动画） | TEST-005 |
| AC-06 | 覆盖层打开，分别按 Esc / 点覆盖层外 / 再按热键 | 均收起且不产生任何 app 切换 | TEST-006 |
| AC-07 | app 退出/新启动后再次唤出 | 键位重新计算且确定性；仍运行的 app 尽量保持原键位 | TEST-007 |
| AC-08 | 首次启动未授权辅助功能 | 显示单页说明 + 跳转系统设置；授权后自动检测并继续；未授权时切换失败给出明确反馈 | TEST-008 |
| AC-09 | 用户在设置中修改唤出键 | 选择冲突键给出提示；保存后立即生效 | TEST-009 |
| AC-10 | 任意状态 | 键帽显示图标+名称、过长截断；空键位为空态；信息不只依赖颜色；纯键盘完成唤出-切换-取消；全程不请求屏幕录制权限 | TEST-010 |

## 非功能要求

- 性能：覆盖层在热键触发后 ≤ 150ms 显示；测量环境 = 本机 Apple Silicon / macOS 26。
- 资源：frontmost 轮询采用低频（约 1s）或事件驱动，空闲时 CPU 占用可忽略。
- 隐私：仅本地存储 app 身份（bundle id/名称）、激活次数与最近激活时间；不采集窗口标题与屏幕内容；不联网。
- 可访问性：键帽文本/背景对比度满足可读性；错误用文字非仅颜色；200% 文本放大不裁切主要操作（覆盖层为键盘形状，按 V1 评估适用性并记录例外）。
