# QA-001：测试计划

上游：[SPEC-001](spec.md)、[DESIGN-001](design.md)；结果汇总：[TRACE-001](traceability.md)、发布记录。遵循[测试规范](../../../.framework/docs/standards/testing.md)。

## 风险、范围与环境

- 风险等级：整体 **low**（本地单机、无网络、无多用户、无敏感数据落盘、失败可回退）。其中 **medium** 两项：AC-05 跨桌面激活可靠性（对可用性影响大，虽有替代方案但影响主体验）、AC-08 权限授权路径（涉及用户信任，失败会阻断使用）。理由：两者不产生外部副作用，但直接影响核心价值与信任，需 spike 实测 + 手动验收。
- 受影响方：仅本机用户；无第三方依赖。版本：macOS 26.6.2、Apple Silicon、Swift 6.3.3。
- 测试环境：本机；无账号、无服务端。数据来源：本机运行中的真实 app。
- 隔离与脱敏：纯函数单测用合成 `AppCandidate` 夹具，不依赖真实前台；手动用例使用真实 app，但仅观测前台变化、不采集屏幕内容；日志不写窗口标题。

## 数据与可靠性

- 夹具：合成 `AppCandidate`（含中文/英文名、首字母冲突、数字开头、超长名）。
- 时间/随机控制：`AppRanker` 接受注入的 `now`，单测不依赖真实时间。
- 外部依赖替代：单测不触达 `NSWorkspace`/`AXUIElement`；适配器用协议抽象便于 mock。
- 失败证据：单测失败保存首次输出；不稳定用例隔离并记录原因/责任/期限。

## 门槛与验收证据

- 本地：`KeyAssigner`/`AppRanker` 单测全绿；快照测试无意外 diff。
- 发布候选：TKT-008 前所有适用人工用例有真实结果记录；AC-05/AC-08 有 spike 结论支撑。
- 上线后：个人使用自测为主，不设服务端 SLO。
