# PRD-001：键盘形状覆盖层的 App 切换器

上游：[RES-001](research.md)；下游：[SPEC-001](spec.md)、[DESIGN-001](design.md)。

## 用户问题与目标

- 目标用户：在 macOS 上同时打开大量 App、跨多个桌面（Space）与分屏办公的重度键盘用户（先服务于 owner 本人，后续开放给同类用户）。
- 使用场景：需要在多个已打开的 App 之间高频切换，手不想离开键盘。
- 当前困难：现有 Cmd+Tab 是线性轮换、无确定性键位；Mission Control 要动鼠标；rcmd 无富视觉键盘；每次切换要么动鼠标、要么多次盲按，缺乏「看一眼就知道按哪个键」的确定性映射。
- 证据来源：owner 个人办公痛点 + [RES-001 竞品空白](research.md)。

核心价值：按一个全局快捷键唤出**键盘形状覆盖层**，每个键位显示一个「正在运行的 App」的图标与名称，按对应键即切换；字母分配确定、可预测，最终形成肌肉记忆。

| 结果指标 | 当前基线/未知 | 目标与时间窗口 | 分母和采集方式 | 指标负责人 |
| --- | --- | --- | --- | --- |
| 单次切 app 的操作步数 | Cmd+Tab 平均 1–4 次轮换（未实测） | 1 次唤出 + 1 次按键 | 手动计时/自测 | 待填写 |
| 切换后是否落在目标 app | 未知 | 成功且覆盖层立即收起 | 手动记录 | 待填写 |
| 首次可用时间（从安装到会切） | 未知 | ≤ 1 分钟（零配置） | 自测 | 待填写 |

> V1 无遥测（隐私原则：不联网、不采集屏幕内容）。指标由 owner 手动观测；若后续开放给他人再引入最小化、脱敏的匿名统计。

## 范围与优先级

- 必需用户任务（按优先级）：
  1. 唤出：按全局快捷键（默认 `⌥+Space`，可配置）唤出覆盖层。
  2. 识别：覆盖层显示当前所有正在运行的 App（图标 + 名称），按确定性规则映射到键盘键位。
  3. 切换：按某键，激活该 App 并立即收起覆盖层。
  4. 取消：Esc / 点击覆盖层外 / 再按唤出键，收起且不切换。
  5. 权限：首次启动引导授予「辅助功能」权限，不申请「屏幕录制」。
  6. 配置：可修改唤出键并做冲突检测。
- 非目标与明确不支持（V1）：
  - 窗口级切换、窗口缩略图/预览（需要屏幕录制，留待后续）。
  - 手动固定键位覆盖（后续迭代）。
  - Hold（按住即显示、松手收起）快速路径（后续迭代）。
  - 切 Space（桌面）数字键、Stage/工作区保存（后续迭代）。
  - 未运行的 App 启动、模糊搜索。
- 现有行为、外部消费者及兼容要求：无既有产品/外部消费者；macOS 15+、Apple Silicon。

## 产品约束

- 角色与资源权限：单机本地工具，无账号、无服务端；仅申请「辅助功能」权限。
- 数据类别与保留：仅本地存储 app 身份（bundle id/名称）、激活次数与最近激活时间（用于字母排序）；不采集窗口标题、屏幕内容；不联网上传。
- 设备/语言范围：macOS 15+、Apple Silicon；先支持英文/中文 app 名显示。
- 可访问性目标：覆盖层为纯键盘驱动；键帽文字与背景对比度满足可读性；错误状态不只靠颜色（用文字）。
- 延迟/容量：唤出到覆盖层显示目标 ≤ 150ms（本机原生）；同时运行 app 数量目标 ≤ 38（键盘键位数），超出截断到 Top 38。

## 风险与决策

- 关键假设：
  1. 仅辅助功能权限即可可靠激活/置前目标 app —— 需 TKT-001 spike 实测。
  2. 跨桌面「跟随系统」切换可接受（接受系统动画与偶发回弹）—— 需 spike 实测体验。
  3. 首字母 + 就近让位的字母分配足够可预测、可形成肌肉记忆 —— 上线后观察。
- 依赖和未知项：macOS 无公开 Spaces API（跨桌面焦点行为不可控）；辅助功能 API 版本差异。
- 影响交付的未知项：假设 1/2 在 accepted 前由 spike 解决，否则需调整方案（如改为「拉回当前桌面」或申请屏幕录制做窗口级）。
