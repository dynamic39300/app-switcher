# PRD-001：键盘形状覆盖层的 App 切换器

上游：[初始调研](research.md)、[多窗口调研 RES-002](multi-window-research-2026-09-24.md)；下游：[SPEC-001](spec.md)、[DESIGN-001](design.md)。2026-09-24 owner 接受按能力区分 App / 窗口的建议并授权系统修改与整体界面优化；此处接受的是产品意图，实施和验收状态见 [TASKS-001](tasks.md)。

2026-09-25 商业化范围更新：本功能的窗口控制与本地隐私边界继续有效；早期“无账号/无网络”描述的是 0.3.2 基线。新商业构建的登录、授权与切换前门禁由 [FEAT-002](../FEAT-002-commercialization/spec.md) 定义，网络请求不包含窗口标题、使用统计或按键内容。

## 用户问题与目标

目标用户是在 macOS 上同时打开大量 App、窗口与桌面的重度键盘用户，先服务 owner 本人。首要任务是手不离开键盘，唤出面板后看清目标并用一个键切换。截图中的多个「窗口 N」既难辨认，也没有可靠控制身份，不能继续把独立键帽当作已经能精确切窗的承诺。

默认面板每个运行 App 进程只占一个键位，以真实图标、名称和清晰键标帮助辨认；Tab 可进入全局窗口模式。只有当前窗口对象可控制、且标题足以区分时才展开，否则该 App 保留一个应用入口并说明范围。窗口切换需要核对实际焦点，失败明确反馈。

| 结果指标 | 当前基线 | 目标与采集方式 |
| --- | --- | --- |
| App 切换步数 | Cmd+Tab 平均轮换次数未实测 | 一次唤出 + 一次映射键；本机人工验证 |
| 目标正确性 | 旧数字窗口不能保证对应，见 RES-002 | App 模式确认目标进程；窗口模式确认目标窗口；失败不能计成功 |
| 目标可辨认 | 大量相同图标/名称 + 数字编号 | 无标题或重复标题不独立占键；图标、App 名与可用标题共同辨认 |
| 首次可用与响应 | 未完成系统测量 | 首次会用目标 ≤ 1 分钟，App 面板显示目标 ≤ 150ms；测试前不宣称达标 |

本期无遥测、账号或网络服务；指标由本机测试与 owner 手动观测，测试资产使用合成标题和应用夹具。

## 范围与优先级

1. 唤出面板的组合键可在设置中录制、保存并在重启后保留，默认 `⌃⌥Space`；既有 F→J 手势保留并可开关。每次唤出默认 App 模式。
2. 运行集合为 `.regular` 且非自身的 App 进程，不再以有无 CG 内容窗口决定 App 是否可切换。
3. Tab 在应用 / 窗口模式间切换。窗口模式按 App 整体判定能力：存在未知、不可控、无标题或重复标题窗口时，保留单 App 入口。
4. 38 个键位均可显示并接受物理按键输入，数字行有映射时出现；补齐方向键选择与 Enter 确认。Esc、外部点击、再按唤出热键均可取消。
5. 以 SF 字体、真实 App 图标、石墨色面板与明确选择边框替换大面积亮蓝键帽；提供模式、数量、加载、回退、空态与中文错误说明。
6. 仅经辅助功能通道读取必要窗口对象与标题；F+J 所需输入监控沿用已有权限边界，不请求屏幕录制。
7. 菜单栏和覆盖层齿轮打开独立原生设置窗口。快捷键草稿与生效值分开，保存成功才替换旧键；无效、已知系统保留 / 已启用系统组合或 Carbon 可检测的排他注册冲突明确反馈，失败保留旧配置及菜单入口。

本期不做窗口缩略图、屏幕截图、用户别名、跨重启窗口记忆、手动固定键位、Hold、主动移动窗口或切 Space、未运行 App 启动、模糊搜索与私有窗口 API。TKT-006 按本次用户要求实现唤出组合键配置，不自定义无修饰双字母手势，也不手动修改各 App 的选择键；冲突检测不能保证发现所有第三方非排他注册（non-exclusive）、事件监听或应用局部快捷键，注册成功不等于系统内绝无其他响应者。

## 约束与取舍

- App 模式请求目标运行实例按正常打开方式呈现窗口并转到前台，系统 / App 决定恢复或创建哪一个窗口；不能把前台 PID 正确当作窗口已经可见，也不把 App 级结果算成精确窗口切换成功。同安装路径的实例有歧义时明确失败并提示选具体窗口；没有 App 包路径时只能精确激活进程，不保证恢复窗口。
- 能枚举窗口、能控制窗口、用户能辨认窗口是三个条件；采用公开 AX 能力门禁与结果验证，不能承诺所有 App、Space 或全屏状态兼容。
- 使用统计仅持久化 App 身份、计数与时间戳；唤出组合键与 F→J 开关单独保存在本地配置，不改统计。标题可能含敏感内容，只保存在当前内存快照，不进入日志、统计或配置；快捷键录制仅在本设置窗口内捕获，不记录逐键输入；不获取屏幕内容、不联网。
- 支持 macOS 15+、Apple Silicon、中英文名称；QWERTY 物理键位包括数字行；最多映射 38 个目标，超额按 rank 截断并提示。
- 视觉验收包括常用与小屏宽度、长中文标题、选中态、键盘全流程和无障碍名称；完整 VoiceOver / 200% 放大符合性需实际检查后判断。
- AX 探测异步且有短超时；慢或无响应 App 不得冻结 App 面板；取消或切模式使迟到结果失效。

核心取舍记录于 [ADR-0001](../../adr/0001-capability-based-window-switching.md)。旧调查对 Chromium AX、所有标题需要录屏、Developer ID 是权限必要条件的推论已由 RES-002 收窄；旧观察不是当前平台定论。
