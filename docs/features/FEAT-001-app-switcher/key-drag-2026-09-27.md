# TKT-018：图标拖拽改键与可关闭引导

日期：2026-09-27；风险 medium。用户授权新增应用图标拖拽到另一按键，并在每次唤醒时提供可关闭的动态演示。执行、自审：Codex；状态：done（本地交付）；版本：0.5.0 local。

## 体验契约

- AC-16：应用模式下，从图标按住移动超过拖动阈值开始；拖到空键移动，拖到已有图标的键互换，其他当前键位不重排。跟随图标、源位淡化、落点高亮与落位反馈可见；不误触应用激活或面板移动。原地或面板外松手取消；Esc 关闭且不保存未落下的拖动。普通点击及按键切换继续可用。
- AC-17：按应用 bundle identity 保存选择键，下一次唤醒和重启后仍生效。唯一应用的固定键优先，其余按原有排序与就近让位自动分配，最多 38 个。未运行的应用不占空键；显式拖到该键会替代其历史绑定。目标键有人时双方保存交换结果；同一应用多个进程时拒绝固定，不猜测身份。窗口模式不固定临时窗口，沿用自动分配。写入失败保持磁盘与内存旧值，显示中文错误。支持恢复默认。
- AC-18：默认每次唤醒应用面板只演示一次，把实际图标的副本拖向另一个可见键并展示落位；绝不改写真实映射、触发应用或增加使用次数。真实操作中止演示；不阻塞键盘或鼠标。引导提供“不再提示”，偏好跨重启保存，工具菜单可重新开启/重播。减少动效时使用静态方向提示；空集合、窗口和加载状态不演示。

## 设计与存储

`KeyAssigner` 接受可选固定键，默认调用兼容原行为；`KeyRemapping` 负责当前快照交换与绑定唯一性。Kit 的 `KeyMappingStore` 是独立 `key-mapping.json` 唯一写入方，schema v1：`version`、`bindings`（bundle identity → 键标签）、`showsDragGuide`。最多 38 个互不冲突的合法键；无 PID、窗口 token、标题、输入轨迹、网络或新权限。缺失使用默认，损坏保留原文件并提示，明确保存前备份损坏文件；原子写成功才变更内存。

选择跨重启的应用身份偏好而非仅移动当次快照，满足肌肉记忆；不跨重启记忆窗口，避免身份不稳定和标题持久化。UI 使用现有 SwiftUI 手势和三套主题，无新增依赖。普通空键与背景继续允许移动整个面板；只有从候选开始的拖动改键。
