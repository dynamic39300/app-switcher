## 运行

从仓库根执行：

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory docs/features/FEAT-001-app-switcher/prototypes/keycap-materials
```

打开 `http://127.0.0.1:8001/?variant=A`。底部切换器或左右方向键换方案；悬停选择、鼠标按住查看键程、松开模拟切换；字母键按下也有相同反馈；Enter 模拟当前目标。Tab 保留浏览器无障碍焦点导航，与原生面板 Tab 切模式不同。原型切换器仅在 localhost / 127.0.0.1 / file 页面显示，不纳入生产构建。

## 设计计划与自审

六个材质基础色：石墨 `#171B22`、钛灰 `#343B46`、银瓷 `#ECEEF0`、墨色 `#26313D`、冰蓝 `#9CCFFF`、烟晶 `#213F48`。中性色透明度表达倒角、接缝、顶面与侧壁，不用任意装饰色。应用示意图标保留识别所需独立色彩。

字型：标题 Avenir Next Demi Bold（小范围展示字体）；正文系统 SF / 苹方；键标 SF Mono / Menlo，像键盘上的刻字。保持应用名可读，禁止为了材质压低关键信息对比。

共同签名：键帽顶面、侧壁、底座三层分离；按下缩短侧壁与阴影。仅活动键出现冰蓝引导。没有声音、持续闪光、全盘倾斜、粒子效果。

```text

┌ 品牌 / 模式 ───────┐     ┌ 品牌 ───────────┐      ┌ 品牌 ────────────┐
```

自审：最初只考虑深浅三种皮肤，不能验证信息层级，故 B 改为顶部目标横条，C 改为侧边预览加紧凑键盘。A 保留现有全键盘布局，是首选落地方向；B/C 的结构变化仅供讨论，未改变已接受 spec。去掉整盘视差、长回弹和模拟触觉承诺，避免趣味盖过效率。

## 交互契约与验收范围

- 默认：细高光、凹面、侧壁及短投影表达材质；空键不响应激活。
- 悬停 / 聚焦：选中轮廓、指示点和目标文字同时更新；不只有颜色。
- 按住：A 3px / B 4px / C 2px 下沉；60ms 进入，150ms 释放；文字和图标跟随顶面，不错位。
- 松开 / 字母键：仅模拟成功，状态栏明确说明；鼠标移出后松开或取消不激活，失焦清除按压态，长按不重复激活。
- 减少动效：禁用过渡及位移，用边界 / 文字静态反馈。
- 原型保持在屏幕上便于重复比较。正式 App 必须立即发起切换，不等待动画结束；此处没有实测原生延迟。
- 只探索正常、悬停、焦点、按下、模拟成功、空键、紧凑视口。加载、失败、权限等沿用已接受 spec，未在本原型重做。
