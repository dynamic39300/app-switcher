# 阶段性里程碑与官网发布准备

## 已确认与尚未确认

2026-09-27，owner 体验后认可当前软件可阶段性封版，希望根据实际产品能力设计官网，并开放给用户使用；同时明确要求安装并使用 Impeccable skill。

- 功能基线：当前 0.5.0。暂停新增桌面功能，后续聚焦官网、必要缺陷修复和发布验证。
- owner 的本机体验认可不替代独立 Mac 安装、全局唤出、权限、升级及第三方兼容矩阵。上一轮全局 Command-J 的自动化验证未闭环，不记录为已通过。
- 本文只记录功能冻结意向和发布计划；未创建新的 Git 提交或标签，未生成正式签名安装包，未上传公网。
- 建议首发明确标注公开测试阶段；公开版本命名和首轮免费公测或现有试用收费模式待 owner 确认。不擅自修改已接受的价格、授权期限或商业门禁。

## 官网现状与设计任务

现有 `web/` 已有 Django 服务及产品、价格、下载、账号、订单、帮助和条款页面，不另建一套脱节的静态官网，也不重写支付与授权逻辑。首页目前仍使用旧的 Command 品牌符号和早期键盘示意，尚未完整表达 0.5.0 的图标、拖拽键位和三主题能力。

本轮按 Impeccable 的 shape 流程明确访客任务与范围，再确定视觉方案；设计完成后进行 critique、audit 与 polish。设计对象首先是公开首页和下载说明，不把官网设计扩展成桌面 App 重做。

- 技能版本 4.4.0，来源为官方 `pbakaus/impeccable` 仓库提交 `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8` 的 `.agents/skills/impeccable`，安装到 `~/.codex/skills/impeccable`，没有覆盖其他技能或启用 hooks。
- 通用安装器下载和 Git 路径受网络影响未完成；官方 npm 安装器的技能包校验文件下载也失败。最终下载官方固定提交归档并通过 ZIP 完整性检查，安装完整技能目录；其中此前已按 Git blob 摘要核对的 46 个文件与最终安装逐字节一致。
- 配套引擎 0.1.6 从官方 npm 源的 `@impeccable/cli-darwin-arm64` 安装，未运行包生命周期脚本，未改变全局 npm 源；由技能自带 launcher 使用版本化缓存启动。
- 已实际执行 `scripts/impeccable context --target web/templates/index.html`，退出码 0，并读取 shape/init 流程。工具未找到 `PRODUCT.md`，但项目已有 `PROJECT.md` 和功能规格；不将工具未识别模板页面的结果解释为没有现有官网。
- 已就首发商业模式及域名、部署、Apple 账号状态发出结构化问题，等待 owner 答复后再确定视觉方案与设计简报；本轮不把规划标成 UI 已实现。

首要访客是希望减少应用切换成本的 Mac 用户。官网的主要任务是让访客理解实际操作，确认机器适用，再完成下载和首次切换；移动端承担了解产品与查阅安装信息，不暗示存在手机 App。

### 应展示的产品事实

| 能力 | 展示证据与边界 |
| --- | --- |
| 唤出后按目标键切换 | 使用真实原生界面与合成工作场景；组合键可配置，不把 owner 保存的 Command-J 写成所有人的默认值 |
| 拖拽应用图标改键 | 展示空键移动、占用键交换、重开后保留；不把临时窗口键位说成永久绑定 |
| 应用与窗口模式 | 默认应用模式，Tab 切窗口模式；仅可靠识别与控制的窗口展开，其余保留应用入口，不承诺所有软件所有窗口 |
| 38 个选择键与键盘操作 | 字母及数字行、方向选择、Enter、Esc；F 后 J 是可开关的快速序列，不写成同时按住 F+J |
| 三套原生主题 | 使用石墨、银瓷、烟晶的实际界面，主题预览需标明对应实际产品 |
| 可移动面板与可关闭引导 | 展示日常工作操作，不用持续动画阻碍阅读，尊重减少动效设置 |
| 数据边界 | 窗口标题、使用统计和按键内容不上传；商业构建仍有账号、授权和更新联网，不宣传整个产品完全离线或零网络 |
| 平台范围 | macOS 15+、Apple Silicon；不暗示 Intel、Windows 或手机端已支持 |

候选信息顺序为：产品与实际演示、核心操作及差异、系统与隐私边界、下载与安装、购买规则、帮助与更新记录。首页不平铺全部技术细节；安装步骤、权限原因、兼容边界放入相应说明页。真实界面素材使用合成窗口内容，不能直接把 owner 桌面或工作窗口发布到官网。

具体视觉构图尚未选定。已有黑底四键菱形品牌需要延续，网站不编造用户数量、好评或未实测的性能指标。
