# SPEC-002：AppSwitcher 商业闭环

2026-09-25 用户要求全面推进、自主决策、目标模式实施。接受意图与实现、验收、发布状态分开；任务和结果见 [TASKS-002](tasks.md)、[QA-002](verification.md)。本功能在现有 0.3.2 本地切换能力上增加商业服务，不重新定义窗口精确控制能力。

## 用户目标与范围

中国大陆个人用户从官网下载 Mac 应用，在浏览器完成统一账号登录、回到 App 开始试用并首次切换，购买期限、续费、恢复订单、申请退款、获得支持和更新。macOS 15+ Apple Silicon 首发；不限账号设备数量、设备类型或并发台数，但尚未支持的平台不承诺可用。Windows、海外支付、自动扣款、团队管理与云同步后置。

每档相同功能：月 9 元/1 日历月、季 24 元/3 日历月、年 78 元/12 日历月，服务端价格为准；调整不改变已付订单。14×24h 全功能试用，由用户登录回 App 后主动开始；每账号一轮，无支付绑定。首次直接购买不追加未来试用；试用中购买保留剩余试用。无设备硬件指纹、窗口标题或按键上传。

生产收款渠道为微信 Native 和支付宝电脑网站支付，未获准和未正确配置的渠道不开放。开发支付模拟仅隔离用于验收，不能在生产启用或算作真实成交。服务需有真实经营主体、联系方式与相应运营资料，未完成生产准备不向公众假报“已上线”。

## 详细规则与质量边界

日期、退款与状态以[商业规则](../../project/commercialization-rules-2026-09-25.md)为产品语义；请求/响应以[共享契约](contract.md)为边界，重大调整同步本规格。渠道支付和身份/权益处理属于 high 风险；需要书面计划、独立审阅、滥用/故障与恢复验证。已有切换 75 项规则及应用唤起回归保持。

本期更新实现选择为 App 内检查更新、可信官网 DMG 下载与正常替换指导，不静默运行下载文件；完整升级流程仍是必需验收。后台部署独立于客户端，不从客户端可变参数决定付款金额或授权签名公钥。业务日志仅含脱敏请求/订单 ID 和可行动错误分类，不含验证码、令牌、私钥、邮件正文、窗口标题或按键。
