# DESIGN-002：商业服务与本地切换的边界

技术选择见 [ADR-0002](../../adr/0002-commercial-service-and-local-license.md)，接口见 [CONTRACT-002](contract.md)。Django 单体服务包含网站、会话、订单、支付适配、权益与后台；生产 PostgreSQL 保证事务和行锁，SQLite 只用于开发/轻量测试。Python 3.12、Django 5.2 LTS 当前安全补丁以及直接/间接依赖以 web/uv.lock 冻结。官网原生 HTML/CSS/JS，无第二套前端服务。

Mac 只增加账号与授权模块，保留 Core/Kit/App 现有分层。静态公钥验证 Ed25519 JWS，本地决定是否允许新切换；网络刷新不放进按键延迟路径。商业候选版本 0.4.0，现有本机 0.3.2 不在外部配置缺失时强行换成不可使用版本。正式商业制品固定服务来源、公钥、商业模式；本地模式清晰隔离，正式脚本拒绝本地模式制品。

## 数据、资产与信任边界

| 数据/资产 | 入口与用途 | 保存/读取边界 | 主要风险与控制 |
| --- | --- | --- | --- |
| 邮箱/验证码 | 身份认证 | 服务端账号与短期哈希验证码；邮件服务只收到验证邮件 | 枚举/撞码/滥发：统一回复、失效/次数/速率限制，不 API 回传或日志明文 |
| 网页会话/授权请求 | 网站到 App 登录 | HttpOnly cookie + CSRF；短期 code 绑定 PKCE 和 state | CSRF、重放、任意重定向：固定回跳、一次兑换、请求过期与错误限制 |
| 桌面 token | 登录会话 | Keychain、服务端 hash；刷新轮换 | 失窃/跨账号：安全存储、归属验证、可撤销，审计不记 token |
| 权益与本地授权 | App 同步/离线 | 服务器为权威；固定公钥签名，不接受 API 临时公钥 | 篡改/回拨/离线撤销延迟：签名、aud/iss/sub/sid/时间校验；7 天上界，不能承诺即时离线撤销 |
| 订单/退款 | 官网及支付渠道 | 账号隔离、数据库事务、不可凭前端自报成功 | 伪造/重放/竞态：验签核对金额商户、幂等键、账号串行、订单账本与查单补偿 |
| 商户和签名秘密 | 受控配置 | 服务器或系统 Keychain，git只保存变量名 | 泄漏：日志脱敏、不入客户端、不入仓库，公开开发密钥绝不可作为生产身份 |
| 工单 | 用户主动填写 | 本账号、授权支持人员 | XSS/越权/资源耗尽：转义、长度限制、归属校验、审计 |
| 使用统计/窗口/按键 | 现有本机流程 | 统计配置本地，窗口标题内存 | 新商业功能不得上传，诊断不自动打包本机内容 |
| 发布包/下载记录 | 管理员发布登记 | HTTPS 官方制品、签名公证、版本hash | 包替换/不安全更新：正式签名与Gatekeeper，可信域名，无静默执行任意URL |

账户资料可通过客服请求注销，业务记录保留需求在正式经营条款落地时核验；生产不无限保留短期验证码/过期会话和诊断日志。实际配置需明确日志轮转、备份保留和负责人，不在缺经营信息时宣称合规认证。

## 一致性与错误处理

购买先创建服务端金额与账号绑定订单；支付外部 I/O 有超时，不把无限请求放在数据库锁内。验证成功后事务锁定账号、幂等记录支付和权益，连续购买保存日期锚点；首次成功发放时间固定，重放不会刷新起点。客户端请求取消不撤销已付款事实。退款申请、渠道受理、最终成功各有状态；需原路查单补偿，不能拿“退款提交成功”当“资金到账”。

第一阶段开发模拟仅在明确 development、独立数据库和显式开关下可用，生产启动检查拒绝模拟支付/开发邮件/弱秘密/非HTTPS来源。第三方未配置时 fail closed 并给用户可理解提示。真实渠道交易、正式签名与公网运营是单独发布门槛，不能用本地绿色测试替代。

迁移为新服务全量初始 schema，不改 usage.json / shortcuts.json。上线前从空库迁移，并在隔离库备份恢复含多订单/退款/试用的合成数据。代码回滚不自动逆向删除订单；数据恢复必须先暂停交易并渠道对账，再补偿恢复点后的支付，避免重复发放。

## UI 选择

中文官网，中性底色与单一蓝色、可操作键盘演示。价格用清晰期限选项，不虚构评价/用户量/节省百分比。账号页显示准确北京时间与可恢复状态，付款/发放状态分开；未有正式下载不放假下载链接。登录先清楚说明将返回 App，回跳失败可重试并保留浏览器成功身份。

App 原生账号窗口与菜单，状态文案区分需登录、可开始试用、试用、付费、需联网、已到期。断网不反复弹广告，不删除用户配置。期满不打断已经开始的切换，新触发与已打开面板的提交都检查本地资格。

## 验证和发布责任

root 集成与发布控制，backend/frontend/desktop 三个独立文件范围并行实现；完成后进行跨模块契约联调和不同 agent 独立审阅。源、依赖、制品版本及实际命令记录在 QA-002。仅本地环境由本任务控制；真实经营身份和外部服务当前无可用证据，已向用户收集名称与状态，不索取聊天明文秘密。
