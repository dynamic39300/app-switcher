# 商业服务单体与本地签名授权

为单人维护的大陆首发选择 Django 单体网站/账号/订单/后台、生产 PostgreSQL 与 macOS 本地签名授权，避免前端、身份和账务各建独立服务；网站采用模板与原生 CSS/JS，减少第二套构建部署链。保留清晰支付适配器和 account/order/entitlement 边界，未来 Windows/海外可共用，无需现在接入后置渠道。

服务端确认支付才产生权益；桌面持有可本地验证的 Ed25519 限时证明，按键不联网。代价是完全离线时退款/撤销不能即时到达，最长受 7 天验证期限及真实权益截止限制；这一取舍已在产品规则明示。设备数量、类型和并发台数不限，安装标识只用于会话撤销，不成为配额。

正式商业构建将服务源与授权公钥固定在签名包中，发布脚本在缺少身份、公钥或公证结果时停止；旧本地版与隔离开发版保留，不用开发通行模式冒充可收费制品。详见 [DESIGN-002](../features/FEAT-002-commercialization/design.md)。
