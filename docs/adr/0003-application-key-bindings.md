# ADR-0003：按应用身份保存选择键

日期：2026-09-27。状态：accepted（用户已授权新增拖拽改键；实现与验收独立记录）。

用户希望调整自动键位并形成使用习惯。选择以 bundle identity 保存应用键位而非只移动当次快照；后者会在唤醒后复原，无法满足连续使用。保留现有 Core → Kit → App 分层，零新增依赖。

Core 负责固定键优先、移动/交换与键位唯一性；Kit `KeyMappingStore` 独占 `key-mapping.json` schema v1 的读写；App 验证会话并在原子保存成功后更新面板。固定键最多 38 个，未运行应用不占当前键位，用户显式覆盖该键会移除对应旧偏好。同包多进程不猜测绑定对象；窗口 token/PID/标题不持久化。

引导开关与键位偏好同文件保存，演示本身不触发保存或激活。损坏配置读取降级但不覆盖；用户明确保存时保留损坏文件备份。写入失败保持旧状态。旧版忽略新增文件，可直接回退；恢复默认只清除键位绑定，保留引导选择。

代价：窗口模式仍自动分配，同包多实例不能持久改键。若未来支持按安装路径区分同包产品或稳定窗口身份，需新增契约/迁移，而非复用临时进程身份。验证与交付见[TKT-018](../features/FEAT-001-app-switcher/key-drag-2026-09-27.md)。
