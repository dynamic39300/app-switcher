# AppSwitcher 首发商业规则与用户服务设计

日期：2026-09-25。本文把最新用户决定与行业调研整理成可评审的产品规则。历史说明：“已确认”来自前次用户答复，其余“建议”保留调研时的表述。**本次用户进一步授权自主决策、全面实施，以下 14 天试用、7 天离线、退款与续费方案纳入 FEAT-002 接受基线**；首发人民币月/季/年定为 9/24/78 元，可配置。接受不表示已经实现、已获商户权限或已上线。实现、验收与外部条件以 [FEAT-002](../features/FEAT-002-commercialization/spec.md) 为准。阶段安排见[商业化里程碑](commercialization-roadmap-2026-09-25.md)。

## 一、已经确认的范围

- 首发面向中国大陆个人用户，经营主体为中国大陆公司或个体工商户，具体登记形式待核实；海外销售后置，保留账号、订单和支付渠道的扩展边界。
- macOS 先行，Windows 后续开发。用户所述“iOS”按桌面 Mac 产品理解，不包含 iPhone / iPad 开发。
- **同一账号不限制设备数量或设备类型，不另设同时在线台数限制。** 未来 Windows 接入同一账号权益；这不表示未开发的平台或所有系统版本现在就受支持。兼容范围须在下载页独立说明。
- 月、季、年由用户主动付款，微信与支付宝；自动扣款后置。不得展示“下月自动续费”或暗含代扣授权。
- App 打开浏览器完成注册 / 登录，随后返回 App；官网提供下载、购买、账号与售后入口。
- 普通用户安装、升级和现有配置保留是首发必需流程。可靠性、界面和交互继续改善，不因增加账号支付而结束兼容性验证。

设备管理用于查看登录会话、主动退出和账号安全，不要求用户因增加电脑而解绑旧设备。不用硬件指纹或隐藏会话配额变相实施设备限制。账号异常处理与个人信息边界要公开说明，不能把后续未讨论的限制当作本次授权的一部分。

## 二、行业做法与本产品选择

以下是从一手来源提炼的做法，不表示 AppSwitcher 已采用这些产品的全部授权条款。

| 参考产品 | 已核验做法 | 对本项目的取舍 |
| --- | --- | --- |
| Microsoft 365 | 提前续费保留尚未用完的期限，延长到期日。[官方续费说明](https://support.microsoft.com/en-us/accounts-billing/subscriptions/problems-renewing-a-microsoft-365-subscription) | 提前买不吃亏；月、季、年切换购买时也保留剩余时间。 |
| JetBrains | 支持个人用户手动提前续费；月 / 年计费周期变更可在当前周期结束后生效。[提前续费](https://sales.jetbrains.com/hc/en-gb/articles/115001327130-Renew-a-personal-subscription)、[周期变更](https://sales.jetbrains.com/hc/en-gb/articles/207737489-Make-changes-to-a-personal-subscription) | 三种期限提供同一套功能，首期采用追加期限，避免按功能升级的折算复杂度。 |
| 1Password | 提供 14 天试用；订阅冻结后保留读取、复制、导出等已有数据访问，限制新增 / 编辑等能力。[试用](https://support.1password.com/membership-billing-policy/)、[冻结状态](https://support.1password.com/frozen-account/) | 建议 14 天全功能试用；到期保留设置与账号入口，暂停核心切换。 |
| BBEdit | 30 天全功能试用后可继续使用免费基础模式。[官方产品页](https://www.barebones.com/products/bbedit/) | 到期降级是一种模式；AppSwitcher 首期不额外设计一套永久免费功能层。 |
| BetterTouchTool | 提供 45 天完整试用。[官方安装说明](https://docs.folivora.ai/docs/getting-started/installation/) | 试用期没有统一行业标准；高频切换工具先用两周观察是否形成使用习惯。该页面不足以推断其按实际使用天数计时。 |
| CleanShot X | 不提供免费试用，提供 30 天退款保证及购买 / 授权恢复入口。[官方 FAQ](https://cleanshot.com/faq) | 免费试用与购买后退款是不同工具；借鉴自助订单恢复，但不把 30 天退款视为必须照搬的标准。 |

## 三、期限购买与提前续费（建议）

### 套餐含义

首期只有同一套个人版功能，购买期限为 **1、3、12 个日历月**。从生效日滚动计算，不按每月 1 日 / 自然季度切段，也不写成固定 30 / 90 / 365 天。价格、季度 / 年度折扣、优惠活动另定；首发人民币结算。

| 用户购买时的状态 | 期限起算规则 |
| --- | --- |
| 没有有效权益，或此前已经到期 | 后端核实成功支付并首次成功发放权益时起算。已过期的空档不收费、不追补。 |
| 已有连续付费权益，包含紧接试用后的待生效付费段 | 优先从全部已安排权益的最终到期时间接着增加本次购买的 1 / 3 / 12 个月。提前买不会减少剩余期限。 |
| 当前试用仍有效，且尚无待生效付费段 | 保留试用剩余时间；首笔付费期限接在试用结束后。后续购买适用上一行，不能再次从试用结束重复起算。 |
| 尚未开始试用而直接购买 | 付费权益立即生效，不在未来再追加一轮试用；结账前明确可先开始试用。 |
| 付费用户换周期购买 | 同功能无需折算差价。例如月费尚未到期时买年费，在现有到期日后追加 12 个月。 |

“支付时间”和“权益实际发放时间”分别记录。若因我方处理延迟造成权益迟发，不让新购 / 已过期用户损失已购买时长。未到期时追加到原期限；如果延迟到发放时已经到期，则从成功发放时重开连续期限。用户付款后自己长时间不打开 App，不因此无限推迟已成功发放的权益。

### 月末、闰年、时区

连续有效的一段付费期限保存最初的日、时、分、秒作为日历锚点；目标月没有该日期时取该月最后一天，下次仍按原锚点计算，不能永久滑到 28 日。已过期再买从新生效日建立锚点。试用后首笔付费以试用结束时间建立付费锚点。此类月份锚点可参考 [Stripe 官方计费周期示例](https://docs.stripe.com/billing/subscriptions/billing-cycle)，这里只借鉴日期算法，不表示使用其支付服务。

日历加月、日期锚点与月末运算固定在 Asia/Shanghai（北京时间）内进行，UTC 仅存储最终时刻，避免北京时间凌晨在 UTC 中属于前一日 / 月而算错期限。首发面向用户统一显示北京时间（UTC+8），确认购买前展示预计开始与到期时间，发放后展示实际结果。有效区间为起点包含、终点不包含；不能只写“某日到期”却让用户猜当天是否还能用。

| 例子（均为北京时间） | 结果 |
| --- | --- |
| 2026-09-25 10:00 生效，买 1 个月 | 到 2026-10-25 10:00；到该时刻停止有效。 |
| 上例在 10 月 10 日提前买 1 年 | 到 2027-10-25 10:00，保留原剩余期限。 |
| 2026-10-25 到期，11 月 3 日 15:00 再买 1 个月并生效 | 到 2026-12-03 15:00，不补收 10 月 25 日到 11 月 3 日。 |
| 2027-01-31 10:00 买 1 个月，并在到期前再买 1 个月 | 第一次到 02-28 10:00，追加后到 03-31 10:00。 |
| 2027-01-31 10:00 买 3 个月 | 到 2027-04-30 10:00。 |
| 2028-02-29 10:00 买 1 年并逐年连续续费 | 第一年到 2029-02-28 10:00，连续延至 2032 年时恢复 02-29 10:00。 |

同一支付通知重复到达只能发放一次；两台设备同时购买两笔真实订单应按账号顺序追加，不得后一次写入覆盖前一次。订单保留套餐、金额、发放和退款记录；不能只留一个无法解释来源的到期时间。已有权益不因价格调整而缩水；新订单按结账时已确认价格执行。

## 四、试用、到期和离线体验（建议）

### 试用起算与到期

建议 **14 个连续日，即 14×24 小时，全功能、不绑付款方式**。官网注册、下载和网页登录本身不消耗试用；登录回 App、阅读初次引导后，由用户点击“开始 14 天试用”，服务端成功开通才起算。按钮旁显示连续计时说明。首次联网开通后由同一账号共用试用起止时间，每个账号一轮；重装、换电脑、升级、退出重登均不重置。

建议试用到期前 3 天和 1 天在菜单 / 账号页轻量提醒；已购买覆盖后续期限时改为显示已安排的付费期限，避免继续催购。付费到期提醒可在 7 天、3 天、1 天显示，邮件提醒由用户选择。没有自动扣款，不需要让用户为避免扣钱去“取消试用”。

到期后的行为：

- 不再执行新的核心应用 / 窗口切换；已经开始的一次切换正常收尾。
- 保留全部本地偏好、快捷键配置、账号、订单、下载更新、帮助与续费入口；不删除配置。配置导出列为建议能力，当前不宣称已经实现。
- 到期后首次使用原快捷键可显示一次可关闭的到期提示，随后不反复截获按键弹广告；明确告知从菜单栏进入续费。续费并同步后恢复使用，保留原配置，重新注册快捷键时照常检查冲突。
- 用户有有效付款但本机无法验证时，提示“请联网验证授权”，不能误写成“请续费”。

### 离线授权

日常切换完全在本机执行，不在每次按键时检查服务器。建议服务端签发本地可校验、有限期的授权凭证：

`本机可用截止 = min(该账号已获批的连续权益截止时间, 最后成功验证时间 + 7×24 小时)`

“连续权益”可包含尚未结束的试用以及已付款、紧接其后的期限；进入付费阶段不应强迫本来有完整有效凭证的用户再次联网。正常联网时后台刷新。离线 7 天不是在购买到期后额外赠送 7 天，也不是每次重启重新获得 7 天。

| 场景 | 用户看到的行为 |
| --- | --- |
| 首次登录、新设备、首次开启试用 | 需要联网，确认同一账号权益。 |
| 已验证且权益有效，暂时断网 | 在本机截止前继续使用，不频繁打断。 |
| 已有付费期限，但超过本机验证期限 | 暂停切换，提示联网验证；验证通过恢复，不要求再付钱。 |
| 联网确认试用 / 付费期限已到 | 提示到期与购买 / 续费，仍可查订单、同步已购。 |
| 本机缓存记录已到期，但无法联网核对账号最新状态 | 暂停切换，提示“本机授权记录已到期，请联网同步；如已购买，无需重复付款”，不直接断言账号真实到期。 |
| 网页续费时 App 离线 | 服务端照常处理订单；App 下次联网自动同步，也有“同步已购权益”入口。 |
| 服务端退款 / 会话撤销，本机完全离线 | 无法即时通知；最迟受现有本地凭证截止约束。联网后同步生效，不声称离线可以即时撤销。 |
| 退出账号 | 清除该账号本机凭证，保留通用设置。其他设备不受影响，除非用户主动选择退出对应会话。 |

7 天是体验与撤销延迟的首发建议，行业并无统一值；例如 JetBrains 的官方在线账号授权支持一定条件下最长 30 天离线使用，但并非本项目必须采用的期限。[JetBrains 官方说明](https://sales.jetbrains.com/hc/en-gb/articles/206544169-Do-I-need-and-internet-connection-to-activate-and-use-JetBrains-products)

时钟回拨、凭证过期、更新失败不得自行生成更长授权；服务端时间、签名与本机计时校验的实现另行设计。长期服务故障需要公告、支持与经记录的补偿，不承诺无服务器条件下可以无限使用，也不承诺不可破解的离线机制。

## 五、普通用户能看懂的账号与支付界面

官网账号中心首期分为四个入口：

| 入口 | 必须解决的问题 |
| --- | --- |
| 我的授权 | 当前账号、试用 / 付费状态、准确到期时间、已安排的后续期限、购买月 / 季 / 年；登录会话查看与主动退出，不显示设备额度。 |
| 订单与退款 | 套餐、金额、支付状态、权益发放结果、渠道订单关联、退款申请 / 进度和票据处理说明。 |
| 下载与更新 | 当前稳定版、系统 / 芯片要求、版本说明、安装帮助和升级说明。 |
| 帮助与反馈 | 不能切换、权限、快捷键冲突、登录回跳、付款未开通等指南；提交问题后有编号与进度。 |

App 内账号页只展示用户需要的当前状态、到期时间、购买 / 续费、同步已购、退出和帮助。技术错误可附可复制的错误编号，不把签名算法、支付回调等工程概念放进普通用户流程。

结账页先明确账号、套餐期限、金额、预计到期日与退款说明，再选择微信 / 支付宝付款。“支付完成”和“权益已开通”分别显示；前者尚未确认后者时展示处理中，并自动查单补偿。不依赖浏览器回跳、付款截图或客户端自报成功开通。

## 六、售后闭环与退款规则（建议）

### 首期可执行的退款承诺

- **首次付费订单：支付成功后 7×24 小时内可申请全额退款。** 即使购买了年费也按该首次订单处理；先试用不会取消这一承诺。若我方迟发权益，申请窗口相应延长，至少保留从实际发放起 7×24 小时。提前购买还未开始的权益同时适用下一条。
- **订单对应的权益区间尚未起算：可申请该续费订单全额退款。** 以服务端安排的生效时间判断，与是否打开过 App、实际使用次数无关。不能用“已下单超过 7 天”拒绝尚未起算的预付续费。
- **已经起算的非首次续费：** 建议一般不提供无理由的剩余天数折现或按天退款。误操作和无法使用可人工核查；重复扣款、未交付和确认故障按下一条处理。该边界在结账前明确展示，最终公开条款需在收费前评审。
- **重复扣款、已付未开通、确认的产品故障：** 有独立核查、补发或退款流程，不一律用上述 7 天窗口挡回。

这里的 7 天是建议的自愿服务承诺，不能写成“所有软件依法必须七天无理由”或“数字软件一概不能退”。具体数字软件 / 账号服务性质、交易条款和法定义务在收费前核验；质量问题责任与自愿退款保证分别处理。[消费者权益保护法（市场监管总局）](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_0a323e046fba43f0b6e9e977f1e8d5fc.html)、[消费者权益保护法实施条例第十九条](https://app.www.gov.cn/govdata/gov/202403/19/513111/article.html)

### 处理过程和权益变化

退款申请 → 受理 / 补充信息 → 审核结果 → 支付渠道退款处理中 → 已退款或失败。用户能看进度和理由，回复统一绑定订单与工单。可先以 **2 个工作日内首次人工回应**作为内部目标；有人负责且能力可持续后，才能作为公开承诺。资金到账时间依渠道结果展示，不冒充可由我方保证的即时到账。

申请退款不立即取消全部权益。只有渠道确认退款后才按退款订单调整：撤销该订单尚未消耗的剩余权益，包括已起算区间的剩余部分；其他未退款订单保留并重新计算连续使用安排。首次订单已用部分不倒扣成债务、不删除配置、不重置免费试用。执行前预览退款后到期时间，遇到多单叠加、部分退款等情况转人工，不让简单减日期误伤其他订单。首期自助申请以整单退款为主，部分退款待规则明确后开放。

最小运营后台覆盖账号、订单、权益发放、退款、支持工单和版本发布记录；人工补发、退款与会话撤销留下操作者和原因。不采集用户窗口标题、屏幕内容或按键原文来证明故障。诊断内容脱敏、可预览后由用户选择提交。

## 七、安装、更新与外部前置条件

**首发必须走通官网真实下载 → 安装 → 首次启动与权限引导 → 登录 / 开始试用 → 首次成功切换 → 更新到下一版本并保留配置。** 用户不需要自己的开发者账号，也不应被要求关闭系统安全保护。

工程建议采用正式 Developer ID 签名、公证的 Mac 分发包；首发至少有 App 内“检查更新”、真实新版本提示、下载 / 替换引导和失败恢复。内置下载安装可评估 Sparkle 2，是否采用及具体更新方式尚未定案；可替换的技术选择不能把普通用户升级验收变成可选项。正式包还需在未参与开发的 Mac 验下载隔离属性、Gatekeeper、首次权限、旧版升级、签名身份和配置保留。当前 0.3.2 仍为本地自签 / ad-hoc 打包，不视作已经跑通商业分发。

用户可以先准备 Apple 开发者身份与实际主体材料、产品域名及组织邮箱、微信 Native / 支付宝电脑网站支付权限。组织与个人 / 个体的 Apple 资格不同，不能仅凭营业执照或 D‑U‑N‑S 就认定组织资格。详细材料、当前状态和工程分工见[前置准备清单](commercialization-prerequisites-2026-09-25.md)。海外渠道、Windows 签名和自动扣款目前不需要申请。

## 八、进入实现前的验收清单

以下是建议用例，**不是已执行的业务测试**。商业规则接受后应落实到对应功能的 spec、接口与测试，不能拿本次文档校验代替这些验收。

1. 新账号只注册不消耗试用；App 明确开始后连续计时；第二台设备、重装与升级不重置，不因设备增多拒绝使用。
2. 试用第 10 天购买月费，保留剩余试用；试用中两台设备分别同时买月费和年费，最终付费期限为试用结束后连续 13 个月；已购买的后续期限不会继续催购；直接购买用户无二次追加试用。
3. 普通日、31 日、2 月和闰年的月 / 季 / 年结果正确，续费锚点不漂移；过期后重购不追补空档。
4. 两笔同时支付均保留、同笔重复通知只发放一次、延迟支付确认不让已过期用户损失期限；价格调整不改变已付订单。
5. 断网 6 天仍有有效凭证可用；超过 7 天但付费未到期提示联网；本机旧记录已到但无法核对时提示同步而非催付；真实到期不额外延长；改时钟和重启不刷新授权。
6. 到期保留配置，正在切换正常收尾，后续不反复弹购买广告；续费同步后恢复原配置与快捷键，冲突有说明。
7. 关闭网页、App 离线、通知延迟 / 遗漏均能查单补发；付款未开通不引导重复付费。
8. 首次订单、未起算续费、已起算续费、重复扣款有对应退款处理；退款失败不假报成功，未退款的其他订单不丢失。
9. 浏览器登录取消、超时、拒绝回跳、冷启动与重复回跳可恢复；账号登录凭证安全保存。
10. 官网正式包在独立 Mac 完成安装、登录、首次切换和升级；付费核心兼容场景按声明范围通过，失败有可理解的提示和支持入口。

## 九、仍需产品决定的少量事项

首发价格与折扣；本稿 14 天试用 / 7 天离线 / 首次 7 天退款建议的最终采纳；已起算续费一般不按天退款的建议边界；实际经营主体与 Apple 身份；首发 macOS / 芯片支持范围；客服负责人和首批用户来源。设备数量、设备类型、国内优先、主动月季年续费不再作为未决问题。
