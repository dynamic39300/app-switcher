# 数据与 AI 产品候选配置

适用于产品运行时使用模型、检索、数据流水线或自动工具执行的项目。仅用 AI 辅助开发的普通应用，按普通工程流程即可，不需要专设模型平台。

候选结构：

```text
src/
  domain/                   # 业务规则与可信授权
  pipelines/                # 适用时的数据处理
  model_adapters/            # 模型输入输出与供应商边界
  tools/                    # 受控动作及参数校验
evals/
  README.md                 # 数据引用、指标、版本与执行命令
  cases/                    # 可入库的脱敏样本
prompts/                    # 版本化提示与用途
docs/
```

目录按实际能力创建。大数据、私有训练集和秘密保存在受控存储，仓库记录版本、摘要、权限、许可和获取方法。

关键选型问题：

1. 规则/搜索/简单工作流能否满足需求？引入模型具体改善什么？
2. 输出是建议还是执行外部动作？谁提供真实身份、授权、幂等和审计？
3. 需要怎样的任务成功率、错误代价、延迟、成本与人工接管？
4. 数据如何更新、删除和隔离租户？如何避免测试集泄漏？
5. 模型或工具版本变化后，哪些 eval 和合同测试必须重跑？

先建立代表性的可重现 eval 与一个端到端切片，再比较供应商、RAG、编排或多 Agent。具体模型与框架版本随项目选型核验，不固化在通用模板中。遵循 [AI 工程](../docs/standards/ai-engineering.md) 与 [安全](../docs/standards/security-privacy.md)。
