# 库、CLI 与 SDK 候选配置

适用于对其他项目提供可复用代码或命令行能力的仓库。核心产品契约是公共 API/命令语义、输入输出、错误与退出码、运行时兼容和发行产物。

```text
src/                        # 实现，按语言惯例调整
tests/                      # 公共行为和兼容消费者
examples/                   # 可运行的消费案例
docs/                       # 使用说明与贡献材料
```

启动时记录支持的语言/运行时/平台矩阵、公共与内部 API 边界、包名/发行位置的 owner、版本策略、依赖范围和许可证。包的使用文档与框架研究样例分别索引。

第一条纵向切片应由一个独立消费者实际安装或导入构建产物，完成正常/失败行为并检查退出码或异常契约；仅在源码目录中测试不等于发行包可用。

破坏性变化明确旧版本支持期、弃用提示和迁移示例。公开发布包属于外部动作，按项目实际授权执行；本项目初始化脚本不创建包注册账号，也不发布任何产物。
