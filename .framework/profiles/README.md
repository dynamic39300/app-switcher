# 采用档位与技术配置参考

`lean / product / platform` 是流程深度；`low / medium / high` 是变更风险。生成器只写采用档位，不安装代码、数据库或云服务。

| 候选配置 | 适用问题 | 文档 |
| --- | --- | --- |
| Web 产品/服务 | UI、API、身份、持久化和部署 | [Web 服务](web-service.md) |
| 数据/AI 产品 | 数据管道、模型能力、评测和工具权限 | [数据与 AI](data-ai.md) |
| 库/CLI/SDK | 稳定公共接口、运行时兼容和发行 | [库与 CLI](library-cli.md) |

这些文件给出**自有选型方法和候选架构**，不是最新版本或流行度推荐。真正选择某项技术时，按 [架构规范](../docs/standards/architecture.md) 查官方支持窗口、许可、漏洞、部署约束和团队能力，记录核验日期；版本以项目 lockfile/工具配置为准。

跨项目一致性优先落在领域语言、身份、错误、时间/金额单位、API/事件契约、观测字段和兼容策略。一个项目只有一个适合的 `src/` 时，不必照搬 monorepo。
