## CI 配置与边界

提供 GitHub Actions 工作流：本框架检查矩阵为 macOS/Linux，新项目模板提供文档检查。Actions 使用已从官方仓库 tag 核实的完整提交 SHA（2026-09-20），分别为 [checkout v4.2.2](https://github.com/actions/checkout/tree/11bd71901bbe5b1630ceea73d27597364c9af683) 和 [setup-python v5.6.0](https://github.com/actions/setup-python/tree/a26af69be951a213d495a4c3e4e4022e16d87065)；这不是“最新版本”声明。后续维护者按官方兼容和安全信息复查、更新并运行 CI。固定完整提交与限制 token 权限符合 [GitHub Actions 官方安全建议](https://docs.github.com/en/actions/reference/security/secure-use)。

未创建远端仓库，**未执行远端 GitHub Actions**；本地成功不代表所有 CI runner 已验证。Windows 的生成器无覆盖 rename 路径已提供，但本次未在 Windows 上运行。

## 尚待实践验证

- 本框架没有业务应用、真实用户验收、生产部署、性能基线或模型 eval 执行结果。
- Claude/Codex/Copilot 互操作依据官方材料核验，未对全部工具版本做端到端运行测试。
- 没有启用平台分支保护、CODEOWNERS 账号、秘密管理系统或定时研究服务。
- 初始化器与检查器不是恶意多用户文件系统上的隔离工具；在可信、非并发修改的本地工作目录使用。文件哈希用于漂移识别，不提供发布者身份或签名认证。
- 框架效果需要通过真实项目试点测量；后续按采用成本、返工、缺陷、交付周期和用户结果调整规则。
