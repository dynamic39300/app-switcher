## 并行约定与范围

TKT-001 确定 API 契约和共享数据模型之后，TKT-002/003/004 可并行。共享契约、迁移与公共测试夹具由集成负责人协调；其他协作者通过明确变更请求调整，不覆盖彼此未提交改动。

本轮允许本地业务实现及隔离测试；没有对生产写入、真实发送、修改外部凭据或公开发布的实际授权。真实实施时在项目既有授权内执行，不能从教学排期推断授权。
