# RFC：待填写提案

关联：[架构规范](../../docs/standards/architecture.md)、[ADR](adr.md)。适用于影响多个模块、团队或消费者且需要讨论的改变。

## 问题、范围与决策问题

现状证据、目标、非目标、受影响方，以及本轮必须决定的具体问题：待填写。

## 提案与替代选项

推荐方案、维持现状及其他可行方案；比较收益、成本、权限/数据影响、NFR、接口兼容、迁移与回退。描述不确定性及验证方案。

## 讨论与结论

谁需要参与、谁最终决策、反馈截止日期、未决项负责人：待填写。记录反对意见及处理理由；不以没有回复推断同意。

## 验收证据与后续

实验/测量/消费者反馈：待产生。明确决定、决策日期和记录：待补。接受后生成/更新 ADR、Spec 与 Tickets；RFC accepted 仅表示提案被接受，不表示迁移完成。
