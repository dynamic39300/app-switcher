# AI Native 项目实践语言

本词汇表定义方法论中的核心材料与治理概念，帮助不同项目和 Agent 使用同一套语言。

## Language

**框架基线（Framework Baseline）**：一组有版本的项目实施原则、规范与可复用模板。
_Avoid_：把某个业务项目的全部实现称为基线。

**项目配置（Project Profile）**：项目对框架深度、技术约束和工作方式作出的明确选择。
_Avoid_：把配置档位等同于风险等级。

**PRD**：描述目标用户、问题、价值、范围和成功标准的产品需求材料。
_Avoid_：将具体实现方案混称为 PRD。

**行为规格（Spec）**：描述系统对外可观察行为、约束和验收条件的约定。
_Avoid_：将技术设计、任务清单和测试结果统一称为 spec。

**技术设计（Technical Design）**：实现行为规格的模块、数据、契约、依赖与迁移方案。
_Avoid_：使用第二份同名 spec 表示技术方案。

**Ticket**：一个有边界、有负责人、有验收条件的可执行工作单元。
_Avoid_：把一次模型对话直接当作完成的工作单。

**证据（Evidence）**：能够追溯到具体版本、环境和执行结果的验证记录。
_Avoid_：把计划执行或模拟输出称为验证证据。

**例外（Exception）**：对适用强制规则的有限偏离，附带责任归属、补偿措施与期限。
_Avoid_：把永久不适用和暂时未达标混在一起。

**规范快照（Framework Snapshot）**：项目采用的特定版本框架副本。
_Avoid_：把快照自动视为最新规范或项目自身需求。
