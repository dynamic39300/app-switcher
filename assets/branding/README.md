## 母版与对应关系

- `app-icon-master.png`：D1「整组旋转」的满版黑底版本，1254 × 1254。四颗圆角键帽组成菱形，底部键帽为冰蓝色；石墨底、银色主体。2026-09-27 通过内置 imagegen 编辑背景，移除外围透明留白、底板轮廓与边框，背景延伸至正方形四角，交由 macOS 处理外轮廓。原始定稿保留在[探索稿](../../docs/project/brand-exploration-2026-09-26/D1-rotated-diamond.png)，不覆盖历史。
- `menu-bar-template.svg`：同一构图的单色线框，小尺寸专用几何；无底板、金属光影或彩色选中键。18 × 18 逻辑尺寸，1.15 pt 线宽，四个独立圆角菱形。
- `menu-bar-template.png` / `menu-bar-template@2x.png`：18 / 36 px 黑色透明模板，后续 AppKit 接入时图像尺寸应设为 18 × 18 pt，`isTemplate = true`，让系统处理明暗和高亮着色。辅助功能名称沿用实际产品名。
- `menu-bar-preview.png`：浅色、深色与菜单展开状态的设计模拟。上方放大，下方按 18 pt 布局；这是模拟预览，不是当前系统截图。

用户已确认的效果图另存为[历史快照 v1](../../docs/project/brand-exploration-2026-09-26/menu-bar-approved-v1.png)。本目录可用于后续资产迭代；历史快照按版本新增，不随生成器运行覆盖。确认过程见[历史记录](../../docs/project/brand-exploration-2026-09-26/README.md#确认与历史归档)。

2026-09-26 后续 TKT-016 / 0.4.1 已将该母版接入应用包图标、面板/账号页品牌位，菜单栏使用两种 PNG 模板。打包脚本生成 ICNS，不重新绘制或改写定稿。实际制品与安装验收以 [0.4.1 记录](../../docs/features/FEAT-001-app-switcher/branding-release-0.4.1.md) 为准；官网本轮未改。产品名继续使用 AppSwitcher。

## 复现

在项目根执行 `swift assets/branding/render-menu-bar.swift`，生成 SVG、两种 PNG 模板和预览。生成器是菜单栏几何的唯一源，使用系统 AppKit / Foundation，无新增依赖，不读取用户窗口或注册菜单栏项。只更新本目录内列出的生成文件，不改应用母版。

验证范围：生成器执行、模板尺寸及透明通道、浅色/深色/选中模拟的视觉检查。实际安装后的系统菜单栏表现需在接入时验收。

2026-09-26 验证结果：Swift 6.3.3 运行生成器成功；`sips` 确认模板分别为 18 / 36 px 且带透明通道；`cmp` 确认选定母版与 D1 原图一致；三种模拟状态已目视检查。框架检查通过（112 个 Markdown，0 错误、0 警告）。此次为低风险设计资产交付，无业务行为变化，未运行业务回归。

## 2026-09-27 满版黑底

用户反馈：应用程序列表中的 AppSwitcher 出现浅色外框，要求黑色铺满，与其他 App 的图标一致。只更新应用图标位图，菜单栏模板不变。编辑工具为内置 `image_gen`，输入为原 D1 母版，`transparent_background=false`。

编辑提示词：保留中央四颗圆角菱形键帽（三银、底部冰蓝）的构图、位置、比例、间距、金属质感与光影；仅把石墨黑背景延伸至整个正方形的四边及四角。移除外层圆角底板轮廓、高光边框、透明或白色留白，不加入文字、框架或第二层底板。输出完全不透明的正方形生产位图，外轮廓由 macOS 处理。

安装与检查见[0.4.3 图标记录](../../docs/features/FEAT-001-app-switcher/icon-full-bleed-2026-09-27.md)。
